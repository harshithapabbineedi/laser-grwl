LASER ENGRAVER DESKTOP APP
==========================

This package converts your Flask laser engraver project
into a standalone Windows desktop application.

WHAT YOU GET
-------------
- Native desktop app window
- No browser needed
- No Python IDE needed after build
- Double-click executable
- LaserGRBL integration
- GCODE generation
- Arduino-compatible workflow

HOW TO BUILD
-------------
1. Install Python
2. Open this folder
3. Double-click build_app.bat

FINAL OUTPUT
-------------
dist/LaserEngraver.exe

FEATURES
--------
- Upload images
- Convert to GCODE
- Job queue
- Open in LaserGRBL
- Live power override
- Modern UI

OPTIONAL NEXT STEP
------------------
Add pyserial for direct Arduino machine control.
